Ya, deployment Replit dapat memakai kuota/kredit, tergantung jenisnya:

Autoscale Deployment: memakai kredit berdasarkan CPU dan RAM yang digunakan.
Reserved VM: biaya bulanan tetap.
Scheduled Deployment: memakai kredit selama job berjalan.
Static Deployment: hosting gratis, tetapi transfer data di atas batas tertentu dapat dikenakan biaya.
Database dan storage dapat memiliki penggunaan/biaya terpisah.
Penggunaan bisa dipantau di Settings → Account usage. Untuk aplikasi API seperti project ini, jika dipublish sebagai Autoscale, pemakaian akan bergantung pada durasi dan beban request, bukan hanya karena deployment aktif.
